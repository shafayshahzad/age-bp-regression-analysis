# Age & Blood Pressure Regression Analysis

## Overview
A statistical study examining the linear relationship between **age** and **blood pressure** 
across a sample of 10 individuals using Simple Linear Regression and Correlation Analysis.

Conducted as part of **Statistics II** at the **Lahore School of Economics**.

---

## Objectives
- Analyze the relationship between age (independent variable) and blood pressure (dependent variable)
- Build a simple linear regression model and interpret its coefficients
- Compute confidence and prediction intervals
- Perform hypothesis testing for correlation and slope

---

## Dataset
| Variable | Role | Range |
|----------|------|-------|
| Age (X) | Independent | 35 – 65 years |
| Blood Pressure (Y) | Dependent | 82 – 118 mmHg |
| Sample Size (n) | — | 10 individuals |

---

## Methodology
- Descriptive Statistics (Mean, Median, SD, Skewness, Kurtosis, Variance)
- Simple Linear Regression (OLS)
- Pearson Correlation Coefficient
- Confidence & Prediction Intervals (90%)
- ANOVA Table
- Hypothesis Testing (α = 0.05)

---

## Key Results
| Metric | Value |
|--------|-------|
| Regression Equation | Ŷ = 107.08 − 0.14X |
| Correlation (r) | 0.127 (very weak positive) |
| R² | 0.016 |
| Standard Error | 11.74 |
| 90% Confidence Interval | 89.70 — 114.27 |
| 90% Prediction Interval | 67.87 — 136.10 |

---

## Hypothesis Testing
**Correlation Test:**
- H₀: ρ ≤ 0 | H₁: ρ > 0
- t_cal = 0.363 < t_critical = 1.860 → **Do not reject H₀**

**Slope Test:**
- H₀: β ≥ 0 | H₁: β < 0
- t_cal = −0.363 > −1.860 → **Reject H₀**

**Conclusion:** No significant linear relationship between age and blood pressure in this sample.
